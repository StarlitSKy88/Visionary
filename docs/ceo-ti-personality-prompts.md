# CEO-TI 人格卡片 - 文生图提示词

> 本文档包含25种CEO-TI老板人格类型的完整文生图提示词中英文对照版。
> **英文版**: 适用于GPT最新图像生成模型(DALL-E 3, GPT-4o Image Generation)
> **中文版**: 适用于Seedance 2.0及国产图像生成模型

---

## 卡片结构规范

所有提示词遵循以下结构：
- **背景**: 山海经古卷风格
- **主体**: 对应人格的象征动物/元素
- **装饰**: 甲骨文、云纹、裂痕
- **文字区**: 人格名称+slogan

### 统一风格标签 (英文)
```
Shanhaijing mythology, ancient Chinese scroll background, ink wash painting style,
paper texture with tea stains, oracle bone patterns, dramatic lighting, cinematic composition
```

### 统一风格标签 (中文)
```
山海经神话风格, 古典中国画卷背景, 水墨画质感, 宣纸肌理, 甲骨文纹样, 戏剧性光影, 电影感构图
```

### 统一格式
- 方向: 竖版 3:4 比例
- 分辨率: 1024x1366 (适配朋友圈分享)
- 底部留白: 用于添加人格名称和slogan
