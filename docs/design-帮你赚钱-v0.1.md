# 帮你赚钱 · 产品设计文档 v0.5

**更新于**: 2026-04-20

## 0. 核心前提（昴君确认）

1. **Phase 1（免费）**：追问式了解用户，像 office-hours 一样一道一道问，AI 思考后再追问下一题
2. **Phase 2（99元）**：多 Agent 生成初稿 → 辩论对抗 → 生成可落地执行的结果
3. **Phase 3（99元内）**：基于报告的追问，报告和行业以外的问题拒绝回答

**核心差异化**：Harness + Agent Team（不是记忆系统）来解决大模型输出不稳定的问题

---

## 1. 核心问题陈述

**用户痛点（已验证）**：
> "每次和豆包对话都像第一次。它不记得你之前纠正过它，一直道歉、奉承，然后给出同样错误的答案。我纠正了10次，它转头又回到原来的错误。"

**更深层的痛点（本次产品要解决的）**：
> 小生意人想要一个"专业又稳定"的商业顾问，但市面上的AI要么给不出专业深度的建议，要么输出时好时坏不稳定。

**目标用户**：不懂提示词工程的小生意人（小卖部老板、夜市炒菜摊主等）

---

## 2. 产品定位

**产品名称**: 帮你赚钱  
**一句话**: 告诉我你的生意情况，我帮你生成一份可落地执行的赚钱方案

**产品形态**: H5 + Web 端（中英文双版本）

**不是什么**:
- ❌ 不是通用AI助手（豆包已经做了）
- ❌ 不是行业知识库（太重，需要专业内容团队）
- ❌ 不是记忆型助手（核心价值不是记住用户）
- ❌ 不是标准问答机器人（不是FAQ形式）

**是什么**:
- ✅ 一个"专业、稳定、可落地"的多Agent商业顾问
- ✅ 核心能力：通过Harness约束 + Agent Team辩论对抗，保证输出质量稳定
- ✅ 用户不需要学提示词，AI通过追问自然理解用户生意全貌

## 3. Phase 1 追问引擎（免费）

### 3.1 触发机制

**追问方式**：按顺序追问（固定顺序：位置/流量 → 规模 → 财务 → 竞争 → 痛点 → 资源 → 经验）

**触发条件**（满足任一即自动进入报告生成，不需要询问用户）：
- 必选维度（5个）全部覆盖
- 追问轮数 ≥ 15 轮

**7个追问维度**：

| 维度 | 示例问题 | 必选？ |
|------|----------|--------|
| 位置/流量 | 开在什么地方？人流量时段分布？ | ✅ |
| 规模 | SKU数量？营业面积？员工数？ | ✅ |
| 财务 | 日均营业额？毛利率大概多少？ | ✅ |
| 竞争 | 周围有同类店吗？你的差异化是什么？ | ✅ |
| 痛点 | 你觉得现在最大的问题是什么？ | ✅ |
| 资源 | 你有什么优势？能投入多少时间/资金？ | ❌（可选） |
| 经验 | 做了多久了？之前做过什么营销尝试？ | ❌（可选） |

### 3.2 追问流程

```
用户输入: "我是开便利店的"

Agent: 第一题（必选：位置/流量）
       "你这个便利店开在什么地方？社区门口、学校旁边、写字楼底商、还是街边？"

用户: "社区门口"

Agent（思考）: 社区门口 → 主要流量是固定社区居民 → 复购率高但客单价可能低
       第二题（必选：规模）
       "那你每天大概有多少人来买东西？人流量大概是什么时段最集中？"

用户: "早上7-9点和晚上6-8点，周末少一些"

Agent（思考）: 朝七晚九，周末少 → 典型的社区作息 → 可判断是刚需型消费
       第三题（必选：财务）
       "那你一天大概能卖多少钱？毛利率大概多少，你知道吗？"

...（直到满足 5个维度覆盖 或 15轮上限，自动进入Phase 2）
```

### 3.3 边界处理

| 情况 | 处理 |
|------|------|
| 用户说"不知道" | 引导用更宽泛的方式回答，如"大概估一个数字就行" |
| 用户跳过 | 记录"跳过"，继续下一题 |
| 用户发语音/图片 | 拒绝："请用文字描述，方便我记录" |
| 用户回答模糊（"还行吧"） | 追问具体化："能说得更具体一点吗？比如和上周比怎么样？" |
| 用户拒绝回答超3次 | 降低维度要求，已覆盖的维度足够就进入Phase 2 |

## 4. Phase 2 多Agent报告生成（99元付费）

### 4.1 Agent Team 架构

```
[用户输入: 所有追问记录]

     ├── Agent-A: 商业分析师
     │   角色：市场分析专家（market-analyst）
     │   输出：《市场机会分析》
     │
     ├── Agent-B: 策略规划师
     │   角色：战略顾问（strategy-planner）
     │   输出：《竞争策略建议》
     │
     ├── Agent-C: 执行顾问
     │   角色：落地执行专家（execution-advisor）
     │   输出：《执行可行性评估》
     │
     └── Agent-D: 财务顾问
         角色：财务分析专家（financial-advisor）
         输出：《投入产出分析》

四个Agent的输出 → Agent-E: 辩论主持人
                              ↓
                     多轮辩论对抗
                              ↓
                     综合结论 → 最终报告
```

### 4.2 辩论规则

**规则**：每个Agent必须指出其他Agent方案中的至少1个风险或漏洞

**轮次上限**：5轮

**辩论规则可配置**：
- 规则A（默认）：互相挑战（每个Agent挑战其他所有Agent）
- 规则B（备选）：投票共识（无法达成挑战时，按多数意见决定）

**切换条件**：Harness连续失败2次 → 自动切换辩论规则

### 4.3 Harness 质量门控

**实现方式**：基于Prompt的判断（LLM-as-judge），每个Agent输出后立即检查

**检查项（4项全过才算合格）**：

| 检查项 | Prompt判断标准 | 不通过示例 |
|--------|---------------|------------|
| 事实范围 | 输出中引用的数据是否在用户回答中找到？如有引用数据需标注来源 | "根据行业数据，便利店平均日流水..."（用户没说行业数据） |
| 可执行性 | 建议是否可以1-2步内描述清楚？是否包含具体动作而非模糊概念？ | "提升服务质量"（模糊）vs "建立会员积分体系，100元积1分"（具体） |
| 优先级依据 | 优先级是否与用户实际情况（如资金、时间、规模）有逻辑关联？ | 说"高优先级"但未说明为什么适合当前用户 |
| 风险评估 | 是否列出了每个建议的潜在风险和应对思路？ | 只说好处不说风险 |

**连续失败处理**：
- 第1次失败：打回对应Agent，要求重写（Prompt优化）
- 第2次失败：打回 + 增加新的分析维度（扩展上下文）
- 第3次失败：切换辩论规则（从"互相挑战"改为"投票共识"）

**全部规则均失败时**：如果规则A和B都连续失败，触发退款流程，99元退还用户，显示"报告生成遇到技术问题，已为您退款"。不生成质量不达标的报告。

### 4.4 最终报告格式

```
═══════════════════════════════════════
        帮你赚钱 · 便利店诊断报告
═══════════════════════════════════════

📍 你现在的情况：
[AI根据追问整理的用户情况描述，3-5行，白话文]

💡 你的赚钱机会（3个核心建议）：

① [机会名称]
   分析依据：[从哪个维度得出]
   具体做法：[1-2步可操作的内容]
   预期效果：[可量化的结果]
   执行优先级：高/中/低

② ...

③ ...

⚠️ 需要注意的风险：
[每个建议的潜在风险]

💰 投入估算：
[预估需要的资金/时间投入]

═══════════════════════════════════════
```

## 5. Phase 3 报告追问（99元内）

### 5.1 ScopeGuard — 行业黑名单

**硬性拒绝（黑名单行业）**：
- 赌博相关行业
- 色情/低俗内容
- 毒品/药品非法销售
- 虚拟货币非法交易
- 野生动物非法贸易
- 国家明令禁止的行业

**拒绝格式**：
```
[拒绝] 抱歉，这个行业不在我们的服务范围内。
如需继续，请修改您的行业描述。
```

### 5.2 追问范围判断

**在范围内**：基于报告内容的执行问题、细节追问、同行业扩展问题

**在范围外**：与报告无关的问题、与用户行业无关的问题、情书/聊天等无关请求

**模糊情况**：请求用户澄清，如"您是想问报告中哪方面的内容？"

### 5.3 追问示例

```
在范围内:
用户: "第一个建议，具体应该怎么开始？"
AI:  [基于报告，给出详细执行步骤]

用户: "我是做餐饮的，这个方案对餐饮也适用吗？"
AI:  [餐饮相关的调整建议]

在范围外:
用户: "帮我写一封催款信"
AI:  [拒绝] 这超出了报告和行业范围，我无法帮助。

用户: "我不是便利店，我是开按摩店的"
AI:  [拒绝] 这份报告是基于便利店情况生成的。
       请重新描述您的生意情况，我会为您生成新的报告。

模糊情况:
用户: "这个方案怎么样"
AI:  [澄清] 您是指报告中的哪个建议？能说得更具体一点吗？
```

## 6. 多语言支持

### 6.1 中英文双版本

| 阶段 | 语言 | 说明 |
|------|------|------|
| Phase 1 追问 | 用户选 | 用户选择中文或英文界面 |
| Phase 2 报告 | 与界面同 | 报告语言跟随用户选择 |
| Phase 3 追问 | 与界面同 | 追问语言跟随用户选择 |

### 6.2 语言切换

- 用户在开始前选择语言，一经选择不可更改（如需更改需重新开始）
- AI追问全程使用同一语言，不混用
- Agent Team所有输出使用用户所选语言

## 8. 定价模型

| 阶段 | 价格 | 内容 |
|------|------|------|
| Phase 1 追问 | 免费 | 直到满足触发条件（5维度覆盖 或 15轮） |
| Phase 2 报告 | 99元/次 | 多Agent生成 + 辩论对抗 + 可落地报告 |
| Phase 3 追问 | 含在99元内 | 基于报告的追问（中英文，付款后24小时内） |

**24小时计时**：从用户付款完成时刻开始计算，24小时后Phase 3追问权限自动失效。

## 12. 竞争优势

| 维度 | 帮你赚钱 | 豆包/通用AI |
|------|----------|-------------|
| 专业深度 | 多Agent辩论，保证分析质量 | 无深度框架 |
| 稳定性 | Harness检查，输出可预期 | 输出随机波动大 |
| 可执行性 | 每条建议都有执行步骤 | 建议泛泛而谈 |
| 追问服务 | 99元包含追问 | 单独付费或不支持 |
